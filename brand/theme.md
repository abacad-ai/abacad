# abacad · theme「porcelain」

纸、墨、三阶灰。一支蓝只在「你正在看的那一页」出现，一点珊瑚只在「坏事发生了」出现。
标志里的两块颜色，只在标志自己身上见面。

唯一来源是 [`frontend/src/index.css`](../frontend/src/index.css)；这份文档解释为什么是这几个值，
以及哪个颜色允许出现在哪里。

## 为什么是这套

- **标志已经是两块高饱和的平色。** 界面再染色，就是两个东西在抢同一件事。chrome 退成灰之后，
  32px 的标志是整页唯一的彩色，蓝点也才有意义。
- **屏幕本身是全站最花的东西。** VNC 画面里有别人的桌面、图标、壁纸。外壳越安静，画面越清楚。
- **字体跟字标同一套骨架。** 字标是 Geist 600 / 字距 −0.035em；界面就用 Geist，不再混第二套
  显示字体。旧的衬线斜体（Iowan Old Style 的 "one quiet place."）退休。
- **不做渐变、毛玻璃、发光。** 和标志的规矩一致：只有平色和 1px 线。

## 颜色

只有一套，没有第二套暗色。

### 蓝和珊瑚的规矩

- 蓝的意思是「你正在看的那一页」：**在线**的点、**焦点**、**下一步提示**、链接。
  一个屏幕面里最多出现一处蓝（标志不算）。
- 珊瑚只给失败和销毁：`last_error` 的点、表单错误、Remove。它**不做**装饰，**不做**强调。
- 主按钮永远是墨，不是蓝。蓝一旦变成按钮色，就会在全站蔓延，标志也就不亮了。
- **不要**在一个页面上同时用蓝和珊瑚做装饰。整个站点里，两色同时出现的地方只有标志。
- 唯一的实心珊瑚是「确认删除」那个按钮——不可逆的动作才配实心；菜单里的 Remove 仍然是
  珊瑚 10% 的底色。其余珊瑚只做图标、点和小字。
- 图标一律单色（`currentColor`）。不要用彩色图标块，不要给图标配 tinted 底。

### 对比度

正文 `#15171A` 对纸 17.9:1；次级 `#63686F` 对白 5.1:1；蓝字 `#0B70AC` 5.4:1；
珊瑚字 `#BF3A37` 5.4:1。蓝色 `#13A7F5` 只做点和面，不做小字。

## 字体

两个字体，都来自 `@fontsource-variable/*`，全部拉丁子集，随构建打包，无外链。

| 角色 | 字体 | 字号 / 行高 | 字重 | 字距 |
|---|---|---|---|---|
| 标志字标 | Geist | 15px / 1 | 600 | −0.035em |
| 显示（登录页） | Geist | 26 → 30 / 1.05 | 600 | −0.04em |
| 页面标题 | Geist | 26 / 1.06 | 600 | −0.04em |
| 区块标题 | Geist | 24 / 1.15 | 600 | −0.035em |
| 对话框标题 | Geist | 17 / 1.2 | 600 | −0.03em |
| 正文 | Geist | 13 / 1.5 | 400 | −0.006em |
| 说明 / 次级 | Geist | 12.5 / 1.45 | 400 | 0 |
| 标签 | Geist | 12 / 1.2 | 500 | 0 |
| 微标（全大写） | Geist Mono | 10 / 1.3 | 500 | 0.16em |
| 地址 / 代码 / 版本 | Geist Mono | 10–11.5 / 1.7 | 400 | 0 |

- 不用衬线体，不用斜体标题，标题字重不超过 600。
- 全大写的微标只用 Geist Mono —— 这是这套界面的「仪表感」来源：`FOR AGENTS`、`SELF-HOSTED VNC HUB`、
  `NO CLOUD · NO RELAY`、版本号、hostname。
- 机器名和地址用 mono；人名、说明、按钮用 Geist。

## 形状与层次

- `--radius: 0.625rem`（10px）。按钮 / 输入框 10px，图标块 6px，卡片 14px，对话框与登录卡 18px。
  标志的圆角是 24%，小尺寸控件跟着它收紧，大尺寸面跟着它放松。
- 所有分隔用 1px `--border`。卡片在纸上只靠一条线和 `--shadow-card`（2px 的 4% 墨）浮起来。
- 只有两级投影：`--shadow-card`（卡片）与 `--shadow-float`（对话框 / 菜单 / toast）。
  没有发光，没有多层阴影，没有 backdrop blur。
- 焦点：1px 蓝描边 + 3px 蓝 30% 光环。这是键盘用户唯一会看到的颜色，所以给蓝。

## 状态

| 状态 | 画法 |
|---|---|
| online | 蓝色 6px 点 + 3px 12% 蓝光晕 |
| failed（last_error） | 珊瑚 6px 点 |
| last seen | `--faint` 6px 点 |
| not seen | `--faint` 1px 空心圈 |

状态只在导航和「只有地址」的机器页出现，不额外加文字标签去解释颜色。

## 落地

- **token 只写在 `frontend/src/index.css`。** 组件里不写 hex，不写第二套灰。
  （品牌标志的两个 fill 是例外：它是图形资产，不是主题色。）
- `npm run lint` 会跑 `frontend/scripts/check-theme.mjs`：组件里出现 `#hex`、`rgb()` 或
  `hsl()` 就失败。要加颜色，先加进 `index.css` 的 token，再用类名引用它。
- 第三方组件（shadcn 生成物）已经对齐 token；新增组件沿用 `bg-card` / `border-border` /
  `text-muted-foreground` 这几个词，不引入新色。
- `color-scheme: light`，不跟随系统暗色。暗色要做就整体重做一套，不要单独给某个组件开洞。
