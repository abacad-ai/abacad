abacad 是通往你自己机器的网关。它的安全模型刻意小到一页能讲完。

## 风险长什么样

- **一个管理员 token 打开所有东西。** 网页登录、API、MCP、每台设备的 WebSocket 都用同一个
  token。3.0 没有每设备 token。
- **hub 能到每台设备。** `gateway` 模式下它保存设备密码，并替客户端登录。
- **hub 是单一入口。** 如果它被攻破，攻击者就处在和 hub 相同的网络路径上，拿着它的凭据。
  把它当成高价值主机。

这就是为什么网络边界比任何单个功能都重要。

## 网络是边界

- **不要把 hub 直接发布到公网。** 放在私有网络、VPN 里，或者至少放在你自己控制的 TLS 和
  反向代理后面。
- **只绑你想要的网卡。** `--listen 127.0.0.1:8787` 放在本地代理后面，或者绑私有局域网地址。
  默认的 `0.0.0.0:8787` 会监听所有网卡。
- **把每台设备的 VNC 端口限制到 hub 的 IP。** 整个网络里只有 hub 需要访问 5900（TigerVNC
  的 `:2` 显示是 5902，iOS VNC Bridge 是 5970）。不要把这些端口开到公网，也不要把它们转发到
  hub 主机上。
- **浏览器走 TLS。** 大多数浏览器的剪贴板需要安全上下文，管理员 token 也不该明文穿过你不
  控制的网络。
- **保持 hub 更新。** 它是一个依赖面很小的二进制；更新就是
  `docker compose pull && docker compose up -d`。

TLS 的 Caddy 和 Nginx 示例见 [TLS 与反向代理](/zh/docs/install/#tls-and-the-reverse-proxy)。

## 凭据

- **管理员 token** 是 32 个随机字节（64 个十六进制字符）。第一次运行时生成、只打印一次；
  除非通过 `ABACAD_ADMIN_TOKEN` 提供，否则保存在 `config.yaml`。改文件（或环境变量）并重启
  即可轮换。所有浏览器会话、agent 连接和保存的 skill 立即失效。
- **设备密码** 保存在 `config.yaml`，权限 `0600`。`gateway` 模式下 hub 需要它们；`l4` 模式
  下 hub 不保存设备密码，因为客户端自己回答设备的挑战。
- **agent skill 里有管理员 token。** 生成的 `SKILL.md` 就是密码。不要放进 git 或共享盘。
- **浏览器会话** 使用由 `cookie_secret` 派生的 HttpOnly、SameSite=Lax cookie。换掉 secret
  会让所有浏览器退出登录。

如果不能在 hub 里保存 macOS 账户密码，创建一个专门用于远程控制的本地 macOS 账户。信任模型
和保存 VNC 密码一样，只是这个凭据能力更强。

## abacad 不做什么

- **没有每设备 token 或角色。** 一个 token 打开所有设备和 API。需要更细的权限，就运行多个
  hub，或者在前面放一个带认证的代理。
- **没有逐动作的人工审批。** `gateway` 模式下 hub 登录后就是传字节。它不检查、不批准每一次
  点击或按键。
- **没有审计日志或录屏。** hub 不解码 framebuffer，也不保留会话历史。
- **不发现、不探测。** 它不扫描网络，也不会主动连接设备。只有真实认证成功的会话才会让设备
  上线。
- **没有 NAT 穿透或中继。** 到 hub 的路径由你负责。

## 一份短清单

1. hub 在可信网络里，不直接暴露到公网。
2. 离开局域网的东西都走 TLS。
3. VNC 端口只对 hub 的 IP 开放。
4. 管理员 token 来自密钥管理器，不是短的人工口令。
5. 备份 `config.yaml`（里面有 token 和设备密码）。
6. 想好 skill 文件或笔记本丢失时怎么轮换 token。

## 模式与取舍

| 模式 | hub 保存凭据 | 客户端看到密码 | 适用 |
| --- | --- | --- | --- |
| `gateway` | 是 | 否 | 你希望浏览器和 agent 不用拿到设备密码就能用。 |
| `l4` | 否 | 是，设备自己的 | 你不想把设备密码放在 hub 上，且客户端能回答挑战。 |
| `direct` | 否 | 不适用（客户端直连设备） | hub 只做目录，你不需要浏览器控制台。 |

无论哪种模式，管理员 token 都控制 hub 本身。
